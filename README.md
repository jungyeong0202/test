# 하단바 포켓몬 (Pokémon Taskbar Pet)

화면 맨 아래(작업 표시줄) 위를 포켓몬이 어슬렁어슬렁 돌아다니는 아주 간단한 데스크톱 펫입니다.

- **설치가 필요 없습니다.** exe 하나를 더블클릭하면 끝이고, 별도 런타임도 필요 없습니다.
- 도트 그림을 코드로 직접 그리기 때문에 **이미지 파일이나 인터넷 연결이 필요 없습니다.**
- 작업 표시줄을 가리지 않고 그 **위에 올라서서** 걸어 다닙니다 (작업 영역을 자동으로 감지).
- 가는 방향을 보고 걷습니다. 오른쪽으로 가면 오른쪽을, 왼쪽으로 가면 왼쪽을 봅니다.
- 마우스로 잡아서 원하는 곳에 옮길 수 있습니다. 놓으면 바닥으로 떨어집니다.
  (뮤는 떨어지지 않고 그 자리에서 이어서 떠 있다가 스스로 제 높이로 돌아갑니다.)
- 포켓몬마다 이동 방식이 다릅니다. 메타몽은 걷지 않고 **뛰어서**, 뮤는 바닥을 딛지 않고 **공중에 떠서** 다닙니다.
- 우클릭 메뉴에서 포켓몬·크기·속도를 바꿀 수 있고, **바꾼 내용은 자동으로 저장**됩니다.
- 몸에서 떠오르는 효과(먼지·하트·Zzz·불꽃·반짝임)는 넣지 않습니다. 움직임은
  포켓몬 자신의 그림으로만 보여 줍니다.
- **가만히 서 있을 때는 원본 GIF 의 애니메이션을 그대로 돌립니다.** 걸을 때는
  걷기 프레임을, 서 있을 때는 원본의 숨쉬기·꼬리 흔들기를 보여 줍니다.
  그 모습을 보라고 **서 있는 시간을 걷는 시간보다 길게**(약 65% 대 35%) 두었습니다.
  '가만히'의 뜻은 이동 방식마다 다릅니다 — 걷는 포켓몬은 멈춰 섰을 때,
  메타몽은 땅에 앉아 쉬는 동안, 뮤는 늘 그렇습니다(발을 딛지 않으니까요).
- **상점과 진화가 있습니다.** 돈을 모아 먹이·성장의 물방울을 사고, 먹이로 친밀도를 올려 진화시킬 수 있습니다.
  진화 줄기는 넷입니다 — 이상해씨→이상해풀→이상해꽃, 파이리→리자드→리자몽,
  꼬부기→어니부기→거북왕, 피카츄→라이츄. 진화체는 메뉴에 나오지 않고 진화로만 만납니다.
  단계가 오를수록 벌이도 늘어납니다(2단계 1.5배, 3단계 2.25배).
- **모의 주식시장**에서 게임 안의 돈으로 여섯 종목을 사고팔 수 있습니다. 실제 돈·실제 주가와는 연결되지 않습니다.
- 윈도우 시작할 때 자동으로 켜지게 할 수 있습니다.
- 다른 창을 클릭해도 항상 맨 앞에 남아 계속 보입니다.

```
피카츄        파이리        이상해씨       꼬부기       메타몽        뮤
pikachu    charmander    bulbasaur    squirtle      ditto       mew

                                  ↓ 진화
                               어니부기
                              wartortle
```

모두 그림에서 들여온 도트입니다. 이동 방식은 셋입니다.

| 방식 | 누가 | 어떻게 |
| --- | --- | --- |
| `walk` | 피카츄, 파이리, 이상해씨, 꼬부기 | 발을 번갈아 디디며 걷습니다. 디딜 때는 몸 전체가 낮고 넓어지고, 발을 들 때는 길게 늘어납니다 (4프레임) |
| `hop` | 메타몽 | 다리가 없어 웅크렸다 늘어나며 폴짝폴짝 뜁니다 (3프레임) |
| `float` | 뮤 | 바닥을 딛지 않고 공중을 떠다닙니다 (4프레임) |

뮤는 중력을 받지 않습니다. 가로로 느긋하게 흘러 다니면서, 떠 있을 높이를 이따금 새로
골라 스르르 옮겨 가고 그 위에서 살랑살랑 위아래로 흔들립니다. 다리가 달랑거리고
꼬리가 살랑이는 것은 프레임에 그려져 있습니다.
도트 하나를 1.5픽셀로 그리므로, `--scale 3` 을 주면 도트 그대로(작게), `--scale 6` 이면 두 배가 됩니다.
`tools/import_sprite.py` 로 원하는 그림을 넣으면 누구든 걷게 만들 수 있습니다.

## exe 하나로 실행하기 (윈도우, 설치 불필요)

`dist\PokemonTaskbar.exe` 를 받아서 **더블클릭하면 끝입니다.** 파이썬도, 별도 런타임 설치도 필요 없습니다.
(윈도우 10 / 11 에 기본 포함된 .NET Framework 4 로 동작합니다.)

```bat
PokemonTaskbar.exe                    :: 피카츄 한 마리
PokemonTaskbar.exe --count 3 --scale 6
PokemonTaskbar.exe -p squirtle --offset 45
```

> 처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다. 서명되지 않은 exe 라서 그렇습니다.
> **추가 정보 → 실행** 을 누르면 됩니다. 찜찜하면 아래처럼 직접 빌드해서 쓰세요.

exe 는 GitHub Actions 에서도 자동으로 빌드됩니다.
저장소의 **Actions** 탭 → 최신 `build-windows-exe` 실행 → **Artifacts** 에서 내려받을 수 있습니다.

## 직접 빌드해서 실행하기 (윈도우)

`csharp` 폴더의 C# 소스를 직접 빌드할 수도 있습니다.
윈도우에 기본으로 들어 있는 .NET Framework 컴파일러(`csc.exe`)를 쓰므로 **역시 설치할 것이 없습니다.**

1. `csharp\run.bat` 더블클릭 (1~2초 빌드 후 바로 실행됩니다)
2. 그 다음부터는 만들어진 `csharp\PokemonTaskbar.exe` 를 직접 실행해도 됩니다

```bat
csharp\run.bat --count 3 --scale 6
csharp\PokemonTaskbar.exe -p squirtle --offset 45
```

도트 그림은 `sprites.py` 에서 생성합니다.
`sprites.py` 를 고쳤다면 아래 명령으로 C# 쪽 데이터를 다시 만들어 주세요.

```bash
python tools/gen_sprites_cs.py
```

> C# 판은 창을 활성화하지 않도록 만들어져 있어 `Esc` 종료가 없습니다. 우클릭 메뉴의 **전부 종료**를 쓰세요.

## 조작법

| 동작 | 결과 |
| --- | --- |
| 포켓몬을 왼쪽 클릭 | 폴짝 뛰면서 머리 위로 하트가 뜬다 |
| 포켓몬을 누른 채 끌기 | 원하는 자리로 옮긴다. 손을 놓으면 떨어져서 그 자리부터 다시 걷는다 |
| 포켓몬을 오른쪽 클릭 | 메뉴 (아래 참고) |
| 포켓몬을 클릭한 뒤 `Esc` 키 | 종료 |

### 우클릭 메뉴

명령줄 없이 마우스만으로 웬만한 건 다 됩니다. **바꾼 내용은 자동으로 저장되어 다음에 켤 때 그대로 나옵니다.**

| 메뉴 | 하는 일 |
| --- | --- |
| 포켓몬 구매 ▸ | 396,000원으로 원하는 포켓몬을 구매합니다 (무작위도 같은 가격) |
| 이 포켓몬 보내주기 | 우클릭한 포켓몬 한 마리만 내보냅니다 |
| 크기 ▸ | 작게 / 보통 / 크게 / 아주 크게 |
| 속도 ▸ | 느리게 / 보통 / 빠르게 |
| 잠시 멈춤 | 제자리에 세워 둡니다 (다시 누르면 재개) |
| 윈도우 시작할 때 실행 | 컴퓨터를 켤 때 자동으로 뜨게 합니다 (윈도우만) |
| 전부 종료 | 프로그램을 끝냅니다 |

### 알림 영역(트레이) 아이콘 — 윈도우 exe 판

작업 표시줄 오른쪽 끝 알림 영역에 포켓몬 아이콘이 하나 생깁니다.
**포켓몬이 화면에 안 보일 때도** 여기서 부르거나 끌 수 있습니다.

| 조작 | 하는 일 |
| --- | --- |
| 두 번 클릭 | 모든 포켓몬을 화면 가운데의 잘 보이는 자리로 데려옵니다 |
| 오른쪽 클릭 → 화면 가운데로 데려오기 | 위와 같습니다 |
| 오른쪽 클릭 → 어디에 있는지 보기 | 화면 크기·작업 영역·창 위치를 보여 줍니다 (`--where` 와 같음) |
| 오른쪽 클릭 → 종료 | 프로그램을 끝냅니다 |

### 진화

| | |
| --- | --- |
| 언제 | 포켓푸드로 **친밀도 10**을 채우고 **10,000px를 산책**한 뒤, `성장의 물방울` 1개가 있으면 진화할 준비가 됩니다 |
| 어떻게 | 두 모습의 하얀 실루엣이 점점 빠르게 번갈아 번쩍이다가, 새하얗게 머문 뒤 진화한 모습이 됩니다 |
| 결정 | 준비가 되면 우클릭 메뉴의 `어니부기로 진화하기`를 눌러 직접 시작합니다 |
| 진행 상황 | 조건이 남아 있으면 우클릭 메뉴에 필요한 포켓푸드·산책 거리가 나옵니다 |
| 그 뒤 | 있던 자리와 보던 방향을 그대로 이어받고, 설정에 저장되어 다음에 켤 때도 진화한 모습입니다 |

### 상점

포켓몬을 우클릭해 `상점`을 열 수 있습니다. **데리고 있는 1초마다 55원**을 얻습니다. 걷든 서 있든 벌이는 같습니다(일시정지 중에는 벌지 않습니다). 등급과 진화 단계에 따라 곱해집니다 — 준전설 3배, 초전설 5배, 2단계 1.5배, 3단계 2.25배입니다. 준전설·초전설은 진화하지 못하는 대신, 일반 포켓몬을 끝까지 키운 것(2.25배)보다 많이 법니다. 포켓푸드(8,000원)는 친밀도를 2 올리고, 먹일 때마다 걸음이 빨라지고 벌이가 2배가 되는 시간을 5분씩 누적합니다. 성장의 물방울은 진화할 때 1개 소비됩니다. 돈과 아이템 수량은 다음 실행에도 남습니다.

`포켓몬 구매`에서 기본 포켓몬 한 마리는 396,000원입니다. 기본 속도(초당 55px)로 약 2시간을 계속 산책해 얻는 금액으로 계산했습니다. 처음 포켓몬 한 마리는 무료로 시작하며, 추가 포켓몬과 무작위 포켓몬은 모두 구매해야 합니다.

### 모의 주식시장

우클릭 메뉴의 `주식시장 열기`를 누르면 별도 오버레이 창이 열립니다. 카드의 거래 수량을 1~99주로 정해 한 번에 매수하거나 매도할 수 있고, 버튼에는 해당 수량의 총 결제액·총 수령액이 표시됩니다. 최근 20회의 가격 변동을 선 그래프와 시작 가격 대비 등락률(%)로 볼 수 있습니다. 카드에는 안정형·성장형·고위험형 성격, 변동폭, 평균 매입가, 수수료를 반영한 내 수익률이 표시됩니다. 매수와 매도에는 각각 2% 수수료가 붙으며, 평가액도 실제 매도 예상액 기준입니다. 종목은 저마다 변동폭이 다르고 20초마다 종목별 호재·악재 뉴스 이벤트가 발생할 수 있습니다. 이벤트가 일어난 종목은 변동성 완화장치로 40초 동안 거래가 멈춥니다. 가격이 100원 아래로 떨어지면 해당 종목은 상장폐지되어 보유 주식이 소멸하고, 30분 뒤에는 성격이 무작위인 새 포켓몬 종목이 같은 자리에 상장됩니다. 오버레이 상단의 빨간 제목 영역을 끌어 원하는 위치로 옮길 수 있고, 보유금과 주식 평가액도 함께 확인할 수 있습니다. 돈과 보유 주식·가격은 저장됩니다. 이 기능은 게임용이며 실제 금융시장이나 현금과 연결되지 않습니다.

**시간이 흘렀다고 저절로 진화하지는 않습니다.** 아끼던 모습이 예고 없이 바뀌면 곤란하니,
조건을 채운 뒤에도 진화할지 말지는 사용자가 정합니다. 가만히 두면 계속 꼬부기입니다.

진화해야 만날 수 있는 포켓몬은 **`포켓몬 구매` 목록에 나오지 않고**, `--count` 로 무작위로
나눠 주지도 않습니다. 직접 이름을 대면(`-p wartortle`) 쓸 수 있습니다.

진화 관계는 `sprites.py` 의 `EVOLUTIONS` 표에 적혀 있습니다. 도트는 자동 생성 구역 안에
들어가므로, 진화 관계는 그 바깥인 이 표에 두어 그림을 다시 들여와도 지워지지 않게 했습니다.

```python
EVOLUTIONS = {
    "squirtle": "wartortle",
}
```

### 효과와 동작

| 언제 | 무엇이 |
| --- | --- |
| 세게 착지할 때 | 몸이 잠깐 **눌린다** |
| 공중에 떠 있을 때 | 몸이 위아래로 **늘어난다** |
| 걸을 때 | 이동 속도에 맞춰 발걸음과 몸의 오르내림이 이어지고, 멈추거나 돌아서기 전에는 잠깐 **감속**한다 |
| 포켓몬을 클릭했을 때 | 폴짝 **뛴다** |
| 가끔 걷다가 | 잠깐 멈춘 뒤 제자리에서 **두 번 폴짝** 뛰며 장난친다 |
| 멈춰 서서 길게 쉴 때 | **낮잠**을 자며 숨쉬듯 몸이 오르내린다 |
| 마우스로 들고 있을 때 | 좌우로 **버둥거린다** |

진화할 때의 번쩍임이 몸 밖으로 퍼질 수 있도록 창에 여백을 두었습니다. 발끝은 여전히 바닥에 닿아 있습니다.

**눌림 / 늘어남 자세는 새로 그린 그림이 아니라 원본 도트를 변형해서 만든 것입니다.**
`tools/import_sprite.py` 의 `--pose-squash` 로 생성합니다. `--eyes` 로 눈 감은
자세도 만들 수 있지만, 눈 깜빡임은 지금 쓰지 않습니다.

```bash
python tools/import_sprite.py 피카츄.png --key pikachu --name 피카츄 --facing left \
    --colors 14 --pose-squash 2 --eyes 0,14,3,17 --eyes 9,14,12,17
```

### 설정 파일

메뉴에서 바꾼 내용은 여기에 저장됩니다.

| OS | 경로 |
| --- | --- |
| 윈도우 | `%APPDATA%\PokemonTaskbar\settings.txt` |
| 그 외 | `~/.config/pokemon-taskbar/settings.txt` |

```
species = pikachu, ditto
scale = 4.5
speed = 55
offset = 0
on_taskbar = false
```

한 줄에 하나씩인 단순한 텍스트라 직접 고쳐도 되고, **파일을 지우면 처음 상태로 돌아갑니다.**
명령줄로 값을 주면 그때만 설정보다 우선합니다 (`--scale 3` 처럼).
다른 경로를 쓰려면 `--settings 파일` 또는 환경 변수 `POKEMON_TASKBAR_SETTINGS` 를 쓰세요.

> **윈도우 시작할 때 실행**은 레지스트리의
> `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run` 에
> `PokemonTaskbar` 값을 만듭니다. 메뉴에서 체크를 풀면 그 값을 지웁니다.
> 현재 사용자에만 적용되고 관리자 권한이 필요 없습니다.
| 터미널에서 `Ctrl+C` | 종료 |

### 내 그림으로 포켓몬 추가하기

가지고 있는 도트 그림(png/jpg)을 그대로 걷게 만들 수 있습니다.

```bash
pip install Pillow                       # 변환할 때만 필요합니다
python tools/import_sprite.py 그림.png --key pikachu --name 피카츄 \
    --colors 12 --preview 확인용.png
python tools/gen_sprites_cs.py           # C# 판에도 반영
```

변환기가 알아서 해 주는 일:

1. 몇 배로 확대된 그림인지 계산해 원래 도트 크기로 되돌립니다
   (같은 색이 이어지는 길이로 칸 크기를 재고, 칸이 밀리지 않게 시작 위치까지 맞춥니다)
2. 칸마다 **면적 평균**을 내어 대표색을 뽑고, `--colors` 개수로 팔레트를 정리합니다
   (매끄럽게 확대됐거나 jpg 로 뭉개진 그림도 안쪽 색이 이깁니다).
   이때 **배경 픽셀은 평균에서 뺍니다** — 그렇지 않으면 가장자리 칸이
   '외곽선 + 배경'의 중간색이 되어 그림 둘레에 옅은 점이 남습니다
3. 바깥에서 이어진 배경만 투명 처리합니다 (눈동자 속 흰색처럼 안쪽에 갇힌 밝은 색은 남깁니다)
4. 맨 아래에서 두 발을 찾아 번갈아 드는 **걷기 4프레임**을 만듭니다
5. `sprites.py` 의 해당 포켓몬 정의를 통째로 갈아 끼웁니다

발이 잘 안 잡히면 `--foot-band`(아래쪽 몇 줄을 발로 볼지), `--foot-rise`(몇 칸 들어 올릴지) 로 조절하세요.
격자 자동 인식이 틀리면 `--grid` 로 가로 도트 수를 직접 지정하면 됩니다.

#### 부위를 직접 움직여 동작 만들기

서 있는 그림 한 장뿐이라 자동 생성이 어색하면, 부위를 사각형으로 지정해 프레임마다 직접 움직일 수 있습니다.
기본으로 들어 있는 네 마리가 모두 이 방식으로 만들어졌습니다.

```bash
python tools/import_sprite.py 피카츄.png --key pikachu --name 피카츄 --colors 14 \
    --facing left \
    --part lfoot:0,35,6,37 --part rfoot:14,36,21,38 \
    --motion "lfoot:0,0;2,-2;0,0;1,-1" \
    --motion "rfoot:0,0;1,-1;0,0;2,-2" \
    --preview 확인용.png
```

- `--facing left` 는 **원본 그림이 왼쪽을 보고 있다**는 뜻입니다. 프로그램이 이동 방향에 맞춰 알아서 뒤집습니다
- `--hop 3` 을 주면 다리가 없는 포켓몬용으로 **[평소 / 웅크림 / 늘어남] 3프레임**을 만들고,
  걷는 대신 폴짝폴짝 뛰어다니게 합니다. 숫자는 납작해지고 길어지는 폭(도트 수)입니다
- `--part 이름:x0,y0,x1,y1` 으로 움직일 덩어리를 지정합니다. 어느 사각형에도 안 들어간 픽셀은 `body` 로 묶입니다
- `--motion 이름:dx,dy;dx,dy;...` 는 프레임별 이동량입니다. 위 예시는 두 발을 번갈아 드는 4프레임입니다
- **발은 위로만 들어 올리세요.** 아래로 내리면 몸에서 떨어져 보입니다
- 네발 포켓몬(이상해씨)은 다리를 셋으로 나눠 번갈아 들면 자연스럽습니다
- 좌표는 `--preview` 로 나온 그림을 보고 잡으면 됩니다

#### 움직이는 GIF 를 원본으로 쓰기

GIF 도 그대로 넣을 수 있습니다. 여러 장이 들어 있으면 `--frame` 으로 고르고,
빼면 첫 장을 씁니다. 투명한 배경은 흰 종이 위에 올려서 읽으므로 따로 지우지
않아도 됩니다.

`--native` 는 **원본이 이미 도트 해상도**(한 픽셀 = 한 칸)라는 뜻입니다. 격자를
재지 않고 크기를 그림에서 그대로 가져오므로 `--grid`/`--rows` 를 손으로 셀
필요가 없습니다. 받은 GIF 들이 모두 그렇습니다.

피카츄는 `assets/images/pikachu-f.gif`(51x46, 112장)에서 이렇게 들여왔습니다.

```bash
python3 tools/import_sprite.py assets/images/pikachu-f.gif \
    --key pikachu --name 피카츄 --colors 14 --facing left --native \
    --idle-frames "$(서로 다른 장 번호들)" \
    --part lfoot:5,39,16,45 --part rfoot:18,39,28,45 \
    --motion "lfoot:0,0;0,-2;0,0;0,0" \
    --motion "rfoot:0,0;0,0;0,0;0,-2" \
    --pose-squash 1 --preview 확인용.png
```

**격자는 쓸 장을 모두 합친 상자로 잡습니다.** 0번 장만 보고 잡으면, 다른 장에서
꼬리가 더 뻗거나 넝쿨이 더 올라갈 때 그만큼 잘립니다 — 피카츄의 꼬리와 이상해씨의
넝쿨 끝이 실제로 잘려 있었습니다. `--idle-frames` 를 주면 합친 상자를 알려 줍니다.

이상해씨는 `assets/images/bulbasaur.gif`(37x38, 99장)에서 이렇게 들여왔습니다.
원본이 이미 도트 해상도라 격자를 자동으로 재게 두지 않고 `--grid`/`--rows` 로
1:1 이라고 알려 줍니다.

```bash
python3 tools/import_sprite.py assets/images/bulbasaur.gif \
    --key bulbasaur --name 이상해씨 --colors 16 --facing left \
    --grid 35 --rows 33 \
    --part lfoot:4,23,12,32 --part rfoot:12,23,20,32 --part bfoot:23,23,31,32 \
    --motion "lfoot:0,0;0,-2;0,0;0,0" \
    --motion "rfoot:0,0;0,0;0,0;0,-2" \
    --motion "bfoot:0,0;0,-1;0,0;0,0" \
    --eyes 10,14,13,17 --eyes 17,13,21,17 \
    --pose-squash 1 --preview 확인용.png
```

**`--idle-frames` 로 서 있을 때의 애니메이션을 넣습니다.** GIF 의 장 번호를
쉼표로 나열하면 그 장들을 `idle0`, `idle1` … 이라는 자세로 넣고, 프로그램이
서 있는 동안 돌립니다. 걷는 프레임과 같은 격자·같은 자르는 상자로 읽으므로
장끼리 어긋나지 않습니다.

**한 바퀴 도는 시간은 원본 GIF 에서 그대로 가져옵니다**(`idle_ms`). 같은 그림이
이어지는 장은 하나로 합쳐 담기 때문에, 장 수만 세서는 원래 속도를 알 수
없습니다 — 이 값이 없던 동안 원본보다 1.4~2.1배 빠르게 돌았습니다.

서로 다른 장만 골라 넘기려면 이렇게 뽑으면 됩니다.

```bash
python3 -c "
from PIL import Image; import sys; sys.path.insert(0,'tools')
import import_sprite as imp
path='assets/images/pikachu-f.gif'
with Image.open(path) as im: n=im.n_frames
seen=[]; last=None
for k in range(n):
    b=imp.read_rgba(path,k,quiet=True).tobytes()
    if b!=last: seen.append(k); last=b
print(','.join(map(str,seen)))"
```

**0번과 2번 프레임은 같아야 합니다**(양발을 다 딛은 자세). `--motion` 의 첫째와
셋째 값을 둘 다 `0,0` 으로 두세요. 어긋나면 `test_imported_sprites_have_a_walk_cycle`
이 잡아냅니다.

**그림 안쪽에 갇힌 투명한 자리는 알아서 비웁니다.** 피카츄처럼 꼬리와 몸 사이가
뚫린 그림은, 흰 종이 위에 올려 읽는 것만으로는 그 구멍이 흰 도트로 굳습니다
(배경 지우기가 가장자리에서 이어진 것만 지우기 때문입니다 — 눈동자 흰자를
지키려고 그렇게 되어 있습니다). 원본의 알파값을 따로 봐서 비웁니다. 몇 칸을
비웠는지 알려 주므로, 숫자가 뜻밖으로 크면 원본을 다시 보세요.

**상자는 다리 전체를 감싸야 합니다.** 처음에 `lfoot:2,24,10,28` 로 잡았더니
발가락(y=29~31)이 상자 밖에 남아, 윗다리만 올라가고 발가락은 그 자리에 붙어
있었습니다 — 걸을 때 다리 중간이 잘려 보입니다. 상자 아래변을 그림 맨 아래줄까지
내리세요. 이건 검사로는 안 잡히고 `--preview` 를 봐야 보입니다.

메타몽처럼 다리가 없는 포켓몬은 부위를 나눌 필요 없이 `--hop` 한 줄이면 됩니다.

```bash
python tools/import_sprite.py 메타몽.png --key ditto --name 메타몽 \
    --colors 12 --facing left --hop 3
```

`--float` 을 주면 바닥을 딛지 않고 공중에 떠다닙니다. 위아래로 흔들리는 것은 프로그램이
알아서 하므로, 프레임에는 달랑거리는 다리나 살랑이는 꼬리만 담으면 됩니다.

```bash
python tools/import_sprite.py 뮤.png --key mew --name 뮤 \
    --colors 16 --facing left --float \
    --part lleg:12,33,21,42 --part rleg:21,33,34,42 --part tail:30,24,50,31 \
    --motion "lleg:0,0;0,-1;0,-2;0,-1" --motion "rleg:0,-2;0,-1;0,0;0,-1" \
    --motion "tail:0,0;0,-1;0,-2;0,-1" \
    --pose-squash 2 --eyes 5,13,11,19
```

### 도트 격자를 잘못 잡으면

들여오기의 첫 단계는 **도트 한 칸이 원본에서 몇 픽셀인지** 알아내는 것입니다.
여기서 틀리면 그 뒤가 전부 어긋납니다. 칸을 실제보다 작게 잡으면 몇 칸마다 한 칸씩
늘어나서, 외곽선이 두꺼워지고 그림이 뭉개집니다. 뮤를 처음 들여올 때 7.82 픽셀짜리를
6.95 로 잡아 실제로 그랬습니다(58x49 로 부풀었고, 제 크기는 52x44 였습니다).

지금은 **도트 경계가 일정한 간격으로 되풀이된다**는 점을 이용해 잽니다. 여러 간격을
대 보고 '경계 위'가 '칸 안쪽'보다 가장 크게 튀는 간격을 고릅니다. 칸 크기의 두 배·세
배도 점수가 높으므로(한 칸 걸러 격자선을 놓는 셈), 최고점에 가까운 것들 중 **가장 작은**
값을 골라야 진짜 한 칸입니다.

그래도 이상하면 `--grid`, `--rows` 로 직접 정할 수 있습니다. 결과가 미심쩍을 때는
`--preview` 로 나온 그림을 원본과 나란히 놓고 **외곽선 굵기**를 보세요. 원본보다
두꺼우면 칸을 작게 잡은 것입니다.

### 손으로 그리기

도트 그림은 이렇게 문자로 정의되어 있어서, 글자만 바꿔도 새로운 포켓몬을 만들 수 있습니다.

```python
rows=[
    "......KK...KK",     # K = 외곽선, Y = 노란 몸,
    ".....KKBK.KBKK",    # R = 볼,     W = 눈 반사광 ...
    ...
]
```

`sprites.py` 의 `POKEMON` 목록에 새 `Pokemon(...)` 을 추가하면 바로 `--pokemon` 으로 부를 수 있습니다.
도트가 촘촘한 그림은 `scale_factor` 를 작게 주면 (`1 / 3` 처럼) `--scale` 과 무관하게 알맞은 크기로 그려집니다.

## 리눅스에서 윈도우용 exe 를 빌드할 때 주의할 점

`tools/build_exe.sh` 는 반드시 **`-sdk:4.8`** 로 컴파일합니다. 이게 빠지면 안 됩니다.

`mcs` 는 기본으로 **Mono 자신의** 클래스 라이브러리를 기준으로 컴파일합니다. Mono 에는
.NET Core 시절 추가된 API 가 들어 있어서, 그냥 빌드하면 윈도우의 .NET Framework 에는
**없는 메서드를 호출하는 exe** 가 만들어집니다. 리눅스에서 Mono 로 돌리면 멀쩡히 돌기
때문에 여기서는 절대 드러나지 않고, 윈도우에서만 `MissingMethodException` 으로 조용히
죽습니다.

실제로 `value.Split(',')` 가 Mono 에만 있는 `Split(char, StringSplitOptions)` 로
컴파일되어, 옵션 해석 첫 단계에서 아무 창도 못 띄우고 죽은 적이 있습니다.

막는 장치는 두 겹입니다.

| 장치 | 언제 걸리나 |
| --- | --- |
| `-sdk:4.8` | 컴파일할 때. `/usr/lib/mono/4.8-api` 의 진짜 .NET Framework 4.8 참조 어셈블리를 씁니다 |
| `tools/check_net48.py` | 빌드 끝나고. 만들어진 IL 의 호출을 하나씩 4.8 참조 어셈블리와 맞춰 봅니다 |

윈도우에서 `csharp/run.bat` 이나 GitHub Actions 로 빌드할 때는 진짜 `csc.exe` 를 쓰므로
이 문제가 없습니다. Actions 는 빌드한 exe 를 실제로 한 번 실행해 보는 단계까지 돕니다.

화면(디스플레이)이 없는 환경에서는 GUI가 필요한 테스트는 자동으로 건너뜁니다.

## 문제 해결 (윈도우)

**아무 반응이 없을 때 — 먼저 `check.bat` 을 두 번 클릭하세요**

exe 와 같은 폴더에 있는 `check.bat` 이 원인을 한 번에 짚어 줍니다.

| `check.bat` 이 확인하는 것 | 왜 |
| --- | --- |
| 파일 크기와 SHA-256 | 내려받다 깨지지 않았는지 |
| "인터넷에서 받은 파일" 차단 표시 | 윈도우가 막고 있으면 **자동으로 풀어 줍니다** |
| .NET Framework 4 설치 여부 | 없으면 exe 가 아예 안 뜹니다 |
| 콘솔 판 실행 결과 | 오류가 있으면 **글자로 그대로 보입니다** |

창이 끝까지 열려 있으니 그 화면을 캡처해서 보내 주시면 됩니다.

**시작 기록(로그) 파일**

프로그램은 켤 때마다 어디까지 갔는지를 아래 파일에 남깁니다. 창이 안 떠도 남습니다.

```
%APPDATA%\PokemonTaskbar\startup.log
```

탐색기 주소창에 `%APPDATA%\PokemonTaskbar` 를 붙여 넣으면 바로 열립니다.
마지막 줄이 `메시지 루프 시작` 이면 프로그램은 잘 뜬 것이고, 그 앞에서 끊겼거나
`!! 실패` 가 있으면 거기가 원인입니다.

> `PokemonTaskbar.exe --check` 를 직접 실행하면 화면·설정·창 위치·스프라이트 목록을
> 이 로그에 적고 바로 끝납니다. 콘솔에 한글을 쓰면 .NET Framework 에서 터지는 경우가
> 있어, 화면 대신 파일로 남깁니다.

**흔한 원인**

| 증상 | 원인과 해결 |
| --- | --- |
| 두 번 클릭해도 아무것도 안 뜬다 | 윈도우가 "인터넷에서 받은 파일"로 막은 경우. 파일 **오른쪽 클릭 → 속성 → 아래쪽 `차단 해제` 체크 → 확인** |
| "Windows에서 PC를 보호했습니다" 창 | **추가 정보 → 실행** 을 누르세요 (서명이 없는 개인 제작 프로그램이라 뜹니다) |
| 잠깐 떴다가 사라진다 | 백신이 지운 경우. 백신의 격리/차단 기록을 확인하고 예외로 등록해 주세요 |
| `.NET Framework` 오류 창 | .NET Framework 4.8 을 설치하세요 (윈도우 10/11 은 기본 포함) |

**포켓몬은 안 보이는데 프로그램은 돌고 있을 때**

1. 알림 영역(작업 표시줄 오른쪽 끝, `^` 를 눌러야 보일 수 있음)의 포켓몬 아이콘을 **두 번 클릭**하세요.
   화면 가운데로 데려옵니다.
2. 그래도 안 보이면 `PokemonTaskbar.exe --where` 를 실행하세요.
   화면 크기, 작업 표시줄 높이, 창이 놓이는 y 좌표를 창으로 보여 줍니다.
3. 오류가 있었다면 이제 조용히 죽지 않고 **오류 내용을 창으로 띄웁니다.** 그 내용을 알려 주세요.

**예전 그림이 계속 나올 때**

exe 를 새로 받아도 이전 것이 그대로 도는 경우가 있습니다. 윈도우는 **실행 중인 exe 를 덮어쓸 수 없어서**,
포켓몬이 떠 있는 상태로 복사하면 조용히 실패하거나 `PokemonTaskbar (1).exe` 로 저장됩니다.

1. 포켓몬을 **오른쪽 클릭 → 전부 종료** (또는 작업 관리자에서 `PokemonTaskbar.exe` 종료)
2. 기존 exe 를 지우고 새 파일을 넣기
3. `PokemonTaskbar.exe --list` 로 지금 실행 중인 빌드에 어떤 도트가 들어 있는지 확인

**포켓몬 위치 조절**
